# Análisis de Datos – Optimización de la Cadena de Suministro

## Descripción

Proyecto desarrollado para el curso **Análisis de Datos (UAIN1008V)**, utilizando Power BI para realizar la limpieza, análisis exploratorio, visualización y definición de KPIs sobre datos de ventas.

## Archivos

- `ventas_alicorp_UAIN1008V.csv`: conjunto de datos utilizado.
- `reporte_analisis_ventas.pbix`: archivo de Power BI con las transformaciones, medidas DAX y dashboard.
- `informe_final.pdf`: informe del proyecto.

## Herramientas

- Power BI Desktop
- Power Query
- DAX

## Reproducción

1. Descargar el archivo `.pbix` y el archivo `.csv`.
2. Abrir el `.pbix` en Power BI Desktop.
3. Si Power BI solicita la ubicación del archivo de origen, seleccionar el CSV incluido en este repositorio.
4. Actualizar los datos para visualizar el dashboard.

## Dependencias

Power BI Desktop, Power Query y DAX.
